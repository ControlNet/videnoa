# Controller sidebar connection status

- The sidebar footer reflects the browser-to-Controller SSE connection, not Worker health or scheduler execution. Sources: `controller-web/src/events/SessionEvents.tsx` and `controller-web/src/shell/AppShell.tsx`.
- The authenticated shell opens native `EventSource("/api/events", { withCredentials: true })`. Healthy and initially connecting states render no status text. An error maps to `unavailable` when readyState is CLOSED, otherwise `reconnecting`. Current labels are `Controller unavailable` and `Controller reconnecting`; the current Controller frontend has no literal `disconnected` label.
- Opening the stream or receiving a valid update restores connected state. Native EventSource owns reconnection; this component adds no retry count, retry timer, or silence timeout. CLOSED has no application-managed restart in this component.
- Errors invalidate page data with reason `reconnect`. Each server connection starts with `refetch`; the frontend invalidates data again to fetch current state. Task, Worker, and scheduler changes arrive as typed delta events.
- `crates/controller/src/operations/events.rs` uses a 64-entry broadcast channel; lag produces `refetch` rather than historical replay. It enables Axum default keepalive (15-second maximum interval in installed Axum source), checks authentication passively on a 30-second interval, and ends the stream on failed authentication or shutdown. Passive checks do not renew session idle expiry.
- A degraded stream can leave displayed progress stale while backend work continues. The status alone cannot diagnose transport interruption, server restart, proxy behavior, or session expiry. Inspect the browser Network entry for `/api/events` and correlated Controller logs to distinguish them. A healthy pending HTTP 200 event-stream request is expected.
- Investigation only: no application behavior changed. Existing lifecycle regression coverage is in `controller-web/src/auth/AuthApp.test.tsx`, test `reports the actual event-stream lifecycle`.
